# Paper Claim–Evidence Map

This file freezes the claims permitted in the paper before prose drafting.

| Claim | Evidence class | Allowed wording |
|---|---|---|
| Explicit five-variable pair matches the strengthened Boolean controls | exact software + direct finite verification | proved for the displayed pair |
| Active sensitivity graphs of the pair are adjacency-cospectral | exact integer characteristic-polynomial equality | exactly cospectral |
| Component-size distributions and active diameter profiles differ | exact graph computation/direct inspection | different global sensitivity geometry |
| Complete n=5, k=5 sparse layer contains a strengthened separation | exhaustive enumeration of C(32,5)=201,376 truth sets | exhaustive for this stated layer |
| Strengthened summary does not determine the residual geometry | explicit counterexample | theorem, unrestricted as a non-determination statement because one counterexample suffices |
| Parity-product lift gives a pair in every essential dimension N>=5 | analytic construction/proof | infinite-family theorem |
| Cartesian-product cospectrality preservation | standard graph theory + applied proof | lemma/standard fact, not novelty |
| Summary-mediated model cannot distinguish a property absent from its summary | elementary factorization consequence | corollary/interpretation |
| The result proves physical speedup or new hardware advantage | no evidence | DO NOT CLAIM |
| Sensitivity graph or spectral sensitivity is newly introduced here | false/established prior art | DO NOT CLAIM |
| Exhaustive n=5 result proves uniqueness of the displayed pair up to all possible Boolean symmetries | not established by current canonical group | DO NOT CLAIM |
| Result is a new law of physics or new computing paradigm | not established | DO NOT CLAIM |

## Paper spine

1. Problem: scalar and spectral summaries may fail to determine global sensitivity geometry.
2. Definitions and established background.
3. Exact five-variable separation theorem and explicit witness.
4. Exhaustive layer verification and reproducibility protocol.
5. Infinite-family parity-product lifting theorem.
6. Consequence for summary-mediated physical/computational models.
7. Limitations: no hardware speedup or physical law is claimed.
8. Reproducibility and artifacts.
